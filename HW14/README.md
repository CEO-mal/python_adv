# HW14 — Менеджер задач: параметры запроса и пагинация

Модели приложения `tasks`: **Category**, **Task**, **SubTask**.
Код: `tasks/views.py`, `tasks/pagination.py`.

## Задание 1. Задачи по дню недели — `GET /api/tasks/`

| Запрос                          | Результат                                  |
|---------------------------------|--------------------------------------------|
| `/api/tasks/`                   | все задачи                                 |
| `/api/tasks/?weekday=вторник`   | задачи, у которых дедлайн во вторник       |

Принимается: `понедельник … воскресенье`, `пн … вс`, `monday … sunday`, `mon … sun`, `1 … 7`
(регистр не важен). Неизвестный день — ошибка 400.
День недели считается по дедлайну в часовом поясе проекта (`TIME_ZONE`).

## Задание 2. Пагинация подзадач — `GET /api/subtasks/`

Не более 5 подзадач на странице, сначала самые новые (`-created_at`).
Следующая страница: `/api/subtasks/?page=2`. В ответе: `count`, `next`, `previous`, `results`.

## Задание 3. Фильтры подзадач — `GET /api/subtasks/`

| Запрос                                               | Результат                                   |
|------------------------------------------------------|---------------------------------------------|
| `/api/subtasks/`                                     | все подзадачи (с пагинацией)                |
| `/api/subtasks/?task_title=Подготовить релиз`        | подзадачи этой главной задачи               |
| `/api/subtasks/?status=done`                         | подзадачи с этим статусом                   |
| `/api/subtasks/?task_title=Подготовить релиз&status=done` | оба фильтра сразу                      |

`task_title` ищет по вхождению в название главной задачи. Статусы:
`new`, `in_progress`, `pending`, `blocked`, `done` (иначе — ошибка 400).
Пагинация работает и вместе с фильтрами.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # и впишите свой SECRET_KEY
python manage.py migrate
python manage.py runserver
```
